# Security Policy

## Supported Versions

`v0.2.0` is the only release so far and is the current supported version. There is no
formal long-term support matrix yet — until there are multiple maintained release lines,
security fixes land on the latest tagged release.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately rather than opening a public
issue. Use GitHub's private vulnerability reporting feature on this repository
(**Security → Report a vulnerability**) once the repository is public, or contact the
maintainer directly.

There is no formal response-time SLA at this stage of the project — reports will be
triaged as promptly as possible on a best-effort basis.
