# Contributing

Miramar AI Platform is source-available and the community is welcome to read the code,
open issues, and file bug reports.

For now, this project is **founder-led**: architecture and roadmap decisions are made by
the maintainer rather than through a community RFC/committee process. This is deliberate
— the goal for the first phase of this project is a clear, coherent product vision before
opening up broad contribution. Significant decisions are recorded as ADRs in
[`docs/adr/`](docs/adr/README.md), so the reasoning behind them is visible even without a
committee process.

That means, at this stage:

- Bug reports and issues are welcome.
- Feature requests are welcome (they inform the [roadmap](ROADMAP.md)).
- Pull requests may be reviewed slowly or declined even if technically correct, if they
  don't fit the current narrow scope.
- There is no formal contributor license agreement or governance process yet — this will
  be revisited once the project has a stable v0.1 release and real users.

If you want to get involved beyond filing issues, open an issue first to discuss before
writing code.
